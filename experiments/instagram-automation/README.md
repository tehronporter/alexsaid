# Instagram automation experiment

This directory preserves the earlier Instagram publishing prototype without shipping it in either production app.

- Files ending in `.txt` are intentionally excluded from the TypeScript and Next.js route trees.
- `vercel.example.json` is documentation, not the repository's active Vercel configuration.
- The production apps retain only user-triggered card downloads and native sharing.

If publishing automation is revisited, update the archived implementation for both products, review current Meta API requirements, add explicit approval and duplicate-post controls, and activate it in a separate release.
